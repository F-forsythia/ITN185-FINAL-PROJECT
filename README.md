To-Do List Web Application

A web-based To-Do List system developed using PHP, MySQL, HTML, CSS, and JavaScript.
This project allows users to manage their daily tasks by adding, updating, completing, and deleting tasks.
It includes user authentication and basic task monitoring features.

Features

Add, update, and delete tasks

Mark tasks as completed

Track task progress

User registration and login system

Task history view

Database integration using MySQL

Technologies Used

PHP – Backend development

MySQL – Database management

HTML, CSS, JavaScript – Frontend development

XAMPP – Local server environment

Installation & Setup

Install XAMPP (or any PHP server environment)

Clone this repository or download the project files

Place the folder inside:

C:\xampp\htdocs\

Start Apache and MySQL in XAMPP

Open phpMyAdmin, create a database (e.g., todo_list)

Import todo_list.sql located in the project directory

Run the project in your browser:

http://localhost/todolist/index.php

Usage

Register or log in to access the system

Add tasks using the input form

View active tasks and mark them as completed

Edit or delete tasks when needed

View completed tasks in task history
